## About Celery Executor

Celery Executor is a Windows desktop tool for Roblox Lua injection and script execution. Its compact interface keeps frequently used controls accessible while providing a practical way to organize and run scripts from a local environment.

Version 2.8 focuses on everyday execution tasks, including one-click injection, grouped script runs, a queue that remains available between actions, and automatic update handling. Alongside its built-in debugger, the included hub offers more than 500 scripts for users seeking a lightweight Windows script executor and script management workspace.

## Frequently Asked Questions

**Does Celery Executor support platforms other than Windows?**  
No. The project is described as a Windows desktop executor intended for Windows 10 and Windows 11 systems.

**What happens when Roblox receives an update?**  
The auto-update engine is designed to help the application track changes, although compatibility may differ after updates made on the Roblox side.

**What is the focus compared with other script executors?**  
Celery Executor prioritizes a compact desktop experience, grouped execution, a persistent queue, and an integrated script hub instead of a large, crowded interface.

**Can using an executor create account or policy concerns?**  
Third-party executors may carry account or policy risks depending on how they are used and the rules of the applicable platform. Check the relevant terms before operating external tools.

**Is workflow data kept on the computer?**  
The project layout provides local directories for hub files, queue data, updater components, and UI resources, allowing much of the workflow to be handled on the local machine.
